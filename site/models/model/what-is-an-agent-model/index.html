What is an Agent Model?

A model is an inference provider configuration with capability assessment and routing rules for agent execution.

Model Fabric Architecture

CodingAgent.in implements a unified model interface behind provider adapters:

  • OpenAI: GPT-4, GPT-3.5 for reasoning tasks
  • Qwen: Specialized for coding and technical tasks
  • Kimi: Korean language model with multilingual support
  • MiniMax: Optimized for Chinese and international contexts
  • Local: Ollama, vLLM, llama.cpp and self-hosted models
  • Custom OpenAI-compatible: Any provider following OpenAI API standards

Routing Policies

Model selection uses intent-based routing with multiple optimization criteria:

  • AUTO: Default router selects based on task requirements
  • QUALITY: Prioritizes best-performing models for critical tasks
  • SPEED: Chooses fastest responding models for time-sensitive work
  • COST: Optimizes for token usage and pricing efficiency
  • PRIVACY: Selects local or private models for sensitive contexts
  • LOCAL: Forces use of on-premises models when available
  • BALANCED: Balances speed, cost, and capability trade-offs

Model Invocation Tracking

Every model usage is persisted with comprehensive metadata:

  • Provider and model name
  • Capability decision (reasoning, coding, analysis, etc.)
  • Input and output token counts
  • Latency measurements
  • Cost tracking
  • Fallback information when models fail
  • Truth state and correlation IDs for audit trails
  • Mission and task references for provenance

Local-First Design

CodingAgent.in prefers local inference when it meets requirements:

  • Repository sensitivity determines private model need
  • Hardware availability (VRAM, CPU) guides model selection
  • Context window size affects model choice for large repositories
  • Offline requirements force local model usage

Deployment Strategies

Models can be deployed through multiple methods:

  • Ollama: Docker-based local inference server
  • vLLM: High-performance serving infrastructure
  • llama.cpp: Lightweight on-device inference
  • LM Studio: Desktop model management and deployment
  • Cloud providers: OpenAI, AWS, GCP, Azure API access

Capability Assessment

Models are evaluated on multiple dimensions:

  • Coding proficiency and language support
  • Reasoning depth for complex problem solving
  • Technical documentation generation
  • Testing and validation capabilities
  • Security analysis skills
  • Code review quality
