What is an Agent Skill?

A skill is a versioned, reviewed workflow definition for recurring tasks with declared tools, inputs, and verification criteria.

Skill Definition

Skills require the following components:

  • name: Unique identifier for the capability
  • version: Semantic versioning for evolution tracking
  • instructions: Step-by-step execution logic
  • required tools: List of needed tool integrations
  • capabilities: Knowledge domains and expertise areas
  • permissions: Allowed action boundaries and scope
  • examples: Sample inputs and expected outputs
  • verification criteria: Success conditions and quality gates

Memory vs Skills Distinction

Critical architectural separation:

  • Memory = what is known or true (facts, data, context)
  • Skill = how a recurring task is performed (procedures, workflows)

Skills transform reviewed procedures into reusable, auditable capabilities that maintain policy compliance across multiple executions.

Skill Lifecycle

Skills evolve through defined states:

  • DRAFT: Initial development and testing
  • REVIEW: Verification and approval process
  • PUBLISHED: Approved for production use
  • REJECTED: Failed review or security concerns
  • DEPRECATED: Retired from active service

Skill Components in Detail

Instructions

Detailed, step-by-step execution flow including:

  • Input validation and transformation
  • Sequential tool calls with parameters
  • Decision logic for branching paths
  • Error handling and recovery procedures

Required Tools

Complete list of tool dependencies including:

  • File system operations
  • Database queries and updates
  • External API integrations
  • Verification and validation tools

Verification Criteria

Measurable success conditions including:

  • Functional requirements validation
  • Security and compliance checks
  • Performance benchmarks
  • Output quality standards

Skill Creation Process

Skills are developed through a structured workflow:

  1. Design: Define objective and success metrics
  2. Develop: Implement instructions with tool integrations
  3. Test: Validate with sample inputs and edge cases
  4. Review: Security, functionality, and performance assessment
  5. Publish: Make available for agent execution

Skill Execution

When a skill executes, agents:

  • Follow instructions step by step
  • Use only declared tools within approved permissions
  • Validate against verification criteria continuously
  • Capture evidence for audit and improvement
