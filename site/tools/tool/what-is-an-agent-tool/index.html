What is an Agent Tool?

A tool is an executable capability with policy enforcement, approval boundaries, and evidence capture for controlled execution.

Tool Gateway Architecture

Every tool call passes through a five-stage security chain:

  1. Policy: Permission validation against agent scope
  2. Approval: Operator decision for consequential actions
  3. Adapter: Transport layer connection and data transformation
  4. Execution: Actual tool function call
  5. Event: Audit trail generation and correlation
  6. Evidence: Provenance capture and verification linkage

Initial Tool Families

The foundation tool set includes:

  • filesystem: Read/write operations with path validation
  • shell: Command execution with safety restrictions
  • git: Repository operations with access controls
  • github: GitHub API integration with rate limiting
  • web_fetch: HTTP requests with security filtering
  • browser: Automated browser interaction with sandboxing
  • postgres: Database operations with transaction controls
  • http: Generic HTTP client with headers and body support
  • storage: Cloud object storage integration
  • artifact: Binary file handling with integrity verification
  • search: Web and internal search capabilities

Execution Controls

No tool execution bypasses security controls:

  • Git push, database writes, browser actions require explicit approval
  • External network egress must be policy-approved
  • Shell commands run in sandboxed environment
  • Secret access requires additional authorization
  • Destructive operations blocked by default

MCP Tool Integration

Model Context Protocol tools integrate through:

  • Discovery: Server capability enumeration
  • Filtering: Policy intersection with agent permissions
  • Authorization: ALLOW/ASK/DENY decision points
  • Execution: Standardized transport handling
  • Audit: Complete evidence trail generation

Tool Adapter Patterns

Tools are implemented through standardized adapters:

  • Protocol-specific: HTTP, gRPC, stdio transports
  • Authentication-aware: Token, certificate, and OAuth support
  • Error handling: Comprehensive failure and recovery logic
  • Rate limiting: Respect for provider quotas and policies

Performance Characteristics

Tool execution optimizes for:

  • Response latency with intelligent caching
  • Resource usage with quota enforcement
  • Security overhead with minimal performance impact
  • Retry resilience with exponential backoff
